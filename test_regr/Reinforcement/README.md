# Reinforcement

This folder groups two reward-based examples.

## Layout

- `hard_example`: a DomiKnowS for training with multiple reward function, which can be unique for each example.
- `easy_example`: a small self-contained demo that computes reward from specific reward function.

## Notes

- Both examples accept generator output directly.
- Both use `logic_str` and `logic_label` to determine whether the reward should be `1` or `0`.
- `Program used: TODO` is kept as a placeholder where applicable.
